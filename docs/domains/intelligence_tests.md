## 入口、配置与权限

系统设置“开启降智检测”对应 `intelligence_enabled`，缺失、无效或读取失败均关闭。公开设置与 HTML 注入包含该布尔值，关闭时侧栏同时隐藏用户和管理员的“降智检测”菜单，并阻止进入用户页；后端独立校验。系统设置中的开关入口保留，开启后恢复两个菜单。关闭时用户列表、详情和画图预览不可访问，管理员通过配置页地址仍能管理配置、查看文本历史，不能发起新检测。已提交的远端任务继续查询并保存结果，避免关开功能造成重复请求。

管理员页面为 `/admin/intelligence-tests`，用户页面为 `/intelligence`。配置身份由来源（`site` 或 `user`）、分组、模型、测试类型组成；同一分组可配置多个模型，每个模型可分别配置糖果与画图测试。身份字段创建后固定，避免把旧记录移入其他分组或模型。新增表单默认选择画图，测试类型选项标明本站生成 HTML 与 Manxue 执行糖果的区别，切换时显示对应调用流程。画图配置支持自定义 `prompt`，最多 32 KiB；留空使用默认的鹈鹕骑自行车 SVG 动画提示词，糖果配置要求此字段为空。编辑提示词等执行字段和删除配置均要求无在途任务；站点检测与用户测试各最多 200 份配置，写入在事务锁内检查数量。

测试使用包含所选渠道的个人站内 API Key。配置表单复用 `/api/v1/keys`，以 `scope=personal` 和所选分组分页查询当前登录用户的 Key；服务端按归属和当前默认或自定义渠道筛选，前端检查停用、过期、耗尽及团队状态。保存和执行前重新解析继承渠道、检查 Key 生命周期及目标分组权限。模型使用原名称调用；同名模型的实际渠道按该 Key 的优先级选择，需要固定检测渠道时为检测创建仅包含该渠道的自定义 Key。

管理配置的 Key 选项只显示名称与编号，选择后填入密码框，也保留手动填写入口。换组立即清空凭据，旧查询取消且不覆盖新分组；关闭弹窗清除候选与明文。保存时解析密钥并只记录原 Key ID，响应仅返回是否已配置；编辑不自动选择新 Key，留空保留原引用。执行前再次检查 Key 的状态、归属、有效期及额度。

Base URL 输入框提供“使用当前网站”，按浏览器当前 `origin` 补全 `/v1`，不携带后台页面路径、查询参数或片段。地址须为公网 HTTPS 地址：画图生成由本站后端访问，糖果测试由检测供应商访问。从本地开发环境填入的 HTTP/localhost 地址不能用于检测。拒绝用户凭据、查询参数、片段与私网地址，提交前再次检查 DNS。

画图测试由本站后端使用保存的 Key、Base URL、模型和提示词调用网关，完成后向 Manxue 提交 HTML 评价。评价请求中的地址、Key 和模型字段使用固定占位值。糖果测试将真实 Key 与 Base URL 发送到 Manxue，由其请求本站。两种测试均应使用专用 Key；计费、余额、订阅和使用记录属于该 Key 的用户。用户侧仅可查看已有分组授权范围内、启用的检测配置与结果；详情和预览重新校验授权，不能通过记录 ID 查看其他分组。登录用户可选择自己的个人 Key 发起画图自测，结果通过 `source=user` 的共享行显示；站点定时检测使用 `source=site`。同一分组、模型的用户测试合并到一行，当前有分组权限的用户可查看，Key 和用户身份不进入公共结果。用户自测只提交自己的 Key ID，调用计入该 Key 的用量，作品与结果公开显示。服务端校验 Key 归属与当前分组权限，拒绝未登录提交；模型、请求协议、推理强度、服务档位、提示词和 API 地址均复制自该 Key 所属渠道的第一个启用系统画图配置，顺序与系统配置列表一致；每次提交重新读取，执行期间保持本次参数快照。缺少启用画图配置的渠道不可自测。用户测试不加入定时调度，同一 Key 有活动任务，或同一渠道、模型在六十秒内提交过任务时拒绝新提交；配置更新和排队写入在同一事务内完成，活动任务期间不能替换执行凭据。

## 远端协议与执行恢复

`internal/intelligence/provider` 使用固定的 `https://manxue.ai/api/v1/tests`：POST 创建，GET 按远端 ID 查询。糖果使用 `candy` 与 Responses；画图在本站生成后使用 `html` 提交评价。创建正文仅含 `benchmark`、固定占位 `base_url`、`api_key`、`model` 与 `html`，不携带 `protocol`、推理强度或服务档位；评价接口会拒绝带生成协议字段的请求。HTML 创建接受 2xx 成功状态码，查询允许返回 `html` 或 `pelican` 标识。已有 `pelican` 远端生成任务继续按原 ID 查询。参考 [Manxue API](https://manxue.ai/api)。

手动检测与可选定时检测共用持久任务队列；定时默认关闭、间隔默认 60 分钟，范围 5 至 10080 分钟。每进程两个工作者，以 PostgreSQL 行锁和租约领取任务；同配置唯一活动任务约束保护多实例及并发点击。新建、调度和结果持久化使用独立表，不在使用记录中伪造检测结果。

在发送糖果创建或画图生成请求前先持久化 `submitting`。进程重启遇到既无远端 ID、也无已保存本地作品的 `submitting` 记录，标为未知；这些请求可能已经消耗额度，须人工核对使用记录后重试。得到远端 ID 后持久化并轮询，服务重启可继续 GET；轮询短暂故障退避重试，远端记录消失或超过观察期限明确结束。旧工作者必须通过租约令牌及期限的比较交换才能写回，不得覆盖新实例结果。HTTP 客户端禁止重定向和创建自动重放，限制响应体 4 MiB、单份 HTML 2 MiB，超限作为错误而非截断成成功。

执行成功与评测通过是不同字段：糖果 `passed` 为通过、`incorrect` 为未通过；画图质量 `normal` 为通过、`degraded` 为未通过，其他无法判定状态以 `status=unknown`、`verdict=unknown` 保存并展示。评估缺失与执行报错分别说明，画图已有作品即使评判未知仍可预览；远端 `classifying` 表示正在评估。接口错误、取消、超时单独显示，不能记成未通过。远端任务 ID、租约及密钥不进入面板响应；回显内容中的密钥与远端 ID 也需要脱敏。

远端错误只保留本地白名单分类与明确的 HTTP 错误状态码，不保存、回显任意错误原文。详情区分鉴权、权限、余额或额度、限流、参数、模型、连接、超时和上游异常；其中带日/周/月用量限额原因的 429 属于额度不足，不能仅按状态码解释为频率限流。空错误占位符不覆盖通过结果；无法识别的非空错误使用通用说明。糖果创建接口失败同样展示安全状态码或超时类型，但不会自动重发，避免重复请求及扣费。旧记录已丢弃的错误原文无法在升级时补回，排障需结合当时使用记录与错误日志。

## 本地生成与 HTML 评价

画图生成调用配置地址下的 `/responses` 或 `/chat/completions`，使用所选模型、提示词、推理强度和服务档位。请求采用流式输出，输出上限为 8192 Token，默认生成超时为五分钟。`first_token_ms` 从本地请求开始计时，在读取到首个非空文本或推理增量事件时记录，忽略心跳、生命周期和空增量；缓冲 JSON 及缺少该观测的历史记录保留空值，界面显示“—”。首 Token 与整次 `duration_ms` 分开保存。解析器接受完整 JSON 或已成功结束的 SSE，提取包含 HTML 与 body 起止标签的完整文档；代码围栏和文档前后说明被移除。断流、Token 截断、空输出或缺少完整文档均不提交评价。生成接口的非成功响应按白名单解析错误分类，账户余额或额度不足会显示对应原因及 HTTP 状态，原始错误正文不持久化。

工作者在生成前保存 `submitting` 与 `phase=generating`；成功后保存实际提示词、HTML、生成 Token 和耗时，并发布 `running` 与 `phase=generated`。下一次认领从已保存的作品发起评价，先保存 `phase=assessing` 和累计尝试次数。HTML 评价使用与参考画廊一致的 `html-gallery-` 加 SHA-256 幂等键，哈希输入为本地记录 ID、一个 NUL 字节和保存的 HTML。临时故障及远端评价过期可复用作品重试，跨重启累计最多五次；永久拒绝或次数耗尽标为未知，作品仍可预览。远端返回的作品和生成统计不覆盖本地保存的数据。

私有 payload 记录本地生成标识和评价尝试次数，详情与恢复查询会读回，面板 JSON 省略这些字段。生成成功后使用独立的短持久化上下文保存作品；即使生成被取消，也尝试保存已经观察到的完整文档。工作者每轮预算六分钟，租约七分钟，覆盖生成及结果写回。关闭总开关阻止排队中的新生成，已有作品继续评价。自定义题目可能偏离评价服务识别的画图任务，结果须结合实际提示词和作品判断。

## 历史与展示

迁移 `304_intelligence_tests.sql` 创建配置与执行记录表，`306_intelligence_drawing_prompt.sql` 增加提示词列，`307_intelligence_user_tests.sql` 增加来源并分开站点与用户历史，启动时由迁移器应用。每份配置保留最新 60 次记录；画图只保留最新 10 份完整 HTML，淘汰正文仍保留对应历史状态和统计。小摘要存入 `record`，问答、HTML 和评测原因独立存入 `payload`，列表 SQL 只读取摘要列，详情或恢复查询时才合并正文，避免列表查询解压全部作品的 PostgreSQL TOAST 数据。

用户页按分组、模型、测试类型与来源显示紧凑行，桌面每行放置小画布、渠道与模型、首 Token 和历史条。站点画图下显示一行共享“用户测试”，尚无人提交时为空行；页头“用户自测”打开只含 Key 选择的表单；候选仅列出绑定启用系统画图检测渠道的个人 Key。每个画图测试只播放最新保留作品的 HTML，最新卡片按与截图一致的桌面画布缩放，避免固定尺寸作品被裁切；历史条从左到右由旧到新，绿色表示“满血”，红色表示“降智”，黄色表示“检测异常”或“结果未知”，灰色表示等待或测试中。行内、历史悬浮图和管理详情使用相同的带图标文字状态牌；页面顶部和独立管理历史提供历史图例。首 Token 耗时在状态牌下方单独显示，错误与未知结果不会标为降智。鼠标移到历史节点或用键盘聚焦时，屏幕居中的浮层显示当次完整年月日、时分秒、状态、首 Token 毫秒值和静态 PNG。截图面板最大宽度 800px，并按视口宽高缩小以完整容纳图片。在历史条内移动只切换当前节点的数据与截图，节点间空隙保持浮层；离开历史条、聚焦到其他区域或按 Escape 后关闭。节点和最新作品标题没有点击打开详情的操作。历史浮层不会启动模型 HTML。

生成成功后尝试捕获并保存截图；已有作品在首次请求截图时补生成。每实例最多运行一个截图浏览器，等待、捕获和保存受请求取消及服务停止控制。PNG 以 base64 存在私有 `payload.thumbnail`，摘要用 `has_thumbnail` 表示可用性；列表和详情 JSON 都省略 PNG 正文。工作者写入评测结果时合并保留已有截图，HTML 的十份保留规则会移除完整文档，截图随六十次历史记录保留。页面共用图片缓存、最多并发两次读取，退出页面时释放图片 URL。

截图适配器通过 chromedp 启动本地 Chromium，使用一次性浏览器目录和最小进程环境。固定虚拟文档请求从已保存的 HTML 返回内容及 CSP sandbox，其余资源、导航、文件和网络请求均由浏览器协议拦截。1280×960 CSS 像素画布运行约 700 毫秒后保存 640×480 PNG，每次捕获上限二十秒、2 MiB。浏览器进程使用 `--no-sandbox` 以支持容器的 `no-new-privileges` 配置，模型文档仍受 CSP sandbox、请求拦截和取消上限约束。运行镜像包含 Chromium；独立二进制部署需安装 Chromium，可用 `CHROMIUM_PATH` 指定可执行文件。截图失败不改变作品或评价结果，后续查看可重试。

## 画图隔离

模型返回的 HTML 是不可信主动内容，不能直接放入主页面或赋予同源权限。已鉴权的 `/runs/:id/preview` 签发五分钟单作品票据，使用固定 JWT secret 的独立 HMAC 域签名。内容路径 `/api/v1/intelligence-tests/preview-content/:ticket` 不依赖面板 JWT，但每次验证票据、总开关、用户有效状态、管理员角色或分组授权，并读取尚未淘汰的作品；权限撤销或作品移除后票据立即不可用。

画图 iframe 使用 `sandbox="allow-scripts"`，不设置 `allow-same-origin`，不开放表单、弹窗或顶层导航。内容响应使用独立 CSP：只允许内联脚本/样式及 data/blob 媒体，禁止网络连接、子框架、Worker、对象与表单提交；禁止浏览器相机、麦克风等能力。主站 CSP 仅追加本站预览路径到 `frame-src`，不放宽主站脚本策略。独立响应避免 `srcdoc` 继承主站 nonce 导致 Canvas 脚本无法运行。历史作品如果依赖外部库或外部素材，预览可能不完整；不为其开放网络或主站会话。

预览响应禁止缓存、禁止 MIME 嗅探，不发送 Referer；票据路径在请求和访问日志中脱敏。票据不具备网关调用权限，不能作为通用代理或任意 URL 下载入口。

## 数据标注台

当前部署的 `/dataset-review/` 提供独立的管理员标注台，默认复核 Kan LLM 的 200 张初标样本（两批各 60 张与扩展测试 80 张），也可切到全部 8,693 张非占位作品。标注台使用本站管理员登录校验，普通用户和未登录访客无法读取样本或修改标签。图片以受保护的 SVG 图片响应展示，页面不执行作品脚本。

满血、降智和无法判定的人工决定与助手初标分开保存，每次保存和撤销均追加修改记录。修改需携带当前版本号，多页面提交旧版本返回冲突并保留页面草稿。训练、验证和测试的归属固定，标签修正不会把图片移到其他集合。导出 ZIP 包含有效标签、人工复核子集、原始初标和修改历史；二分类文件排除无法判定样本，`human_only` 文件排除未经人工确认的助手初标。

标注服务位于部署目录 `/opt/moonup-review/app`，由 `moonup-dataset-review.service` 运行，监听 `127.0.0.1:8096`；主站代理把 `/dataset-review/` 转发到该服务。只读数据位于 `/opt/moonup-review/data`，人工修正使用 SQLite 保存在 `/var/lib/moonup-review/reviews.sqlite3`。备份运行中的 SQLite 使用其在线 backup API，避免仅复制数据库主文件而遗漏 WAL。该服务独立启停，标注修改不回写线上检测历史。

## 接口与实现位置

管理接口前缀 `/api/v1/admin/intelligence-tests`：GET 列表、POST 新增，`/:id` PUT/DELETE，`/:id/run` POST，`/:id/runs` GET，`/runs/:id` GET 详情及 `/runs/:id/preview` GET 签发预览，`/runs/:id/thumbnail` GET 读取已鉴权的 PNG 截图。用户 `/api/v1/intelligence-tests` 提供 GET 列表、详情、预览和截图，以及 POST `/run` 自测；提交正文仅包含 `api_key_id`，成功返回 202 队列记录。预览内容返回 HTML，截图返回 PNG，其余接口遵循既有面板 JSON envelope 与权限中间件。

远端请求和结果类型在 `backend/internal/intelligence/remote/`，HTTP 客户端在 `backend/internal/intelligence/provider/`。任务编排在 `backend/internal/intelligence/service.go`，本地生成与评价状态在 `drawing.go`，网关生成及协议解析在 `provider/generation.go`，用户提交校验在 `community.go`，SQL 仓储在 `backend/internal/intelligence/postgres/repository.go` 和 `community.go`，面板、预览与截图读取在 `backend/internal/intelligence/httpapi/`；Wire 管理工作者启动及退出。前端页面、共享结果组件和 API 分别位于 `views/admin/IntelligenceTestsView.vue`、`views/user/IntelligenceView.vue`、`components/intelligence/` 与 `api/intelligence.ts`。
